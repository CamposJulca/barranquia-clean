# Sesiones

Artefactos de **sesiones puntuales** con el cliente o internas: presentaciones, validaciones acotadas a un rango de fechas, informes de cálculo con ejemplos concretos. Tienen **valor histórico** y se preservan tal como se entregaron — no son documentación viva que evoluciona con el producto.

## Convención

- Cada subdirectorio es `YYYY-MM-DD` correspondiente a la fecha de la sesión o del informe.
- Si un documento se actualiza después de la fecha, **no se reescribe**: se crea una nueva entrada bajo otra fecha o se documenta la actualización en el doc canónico (`correcciones/DOCUMENTO_TECNICO_FUNCIONAL_JOZ.md`).
- Para documentación viva del producto, ver `joz/docs/README.md`.
